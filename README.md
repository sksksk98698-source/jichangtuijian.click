## 💻 本地开发与构建

### 1. 环境准备
- Node.js `>= 20.0.0`
- pnpm `>= 9.0.0`

### 2. 克隆与依赖安装
```bash
git clone https://github.com/sksksk98698-source/jichangtuijian.click.git
cd jichangtuijian.click/myscholar

# 安装依赖
pnpm install
```

### 3. 本地开发调试
```bash
pnpm dev
# 访问 http://localhost:4321
```

### 4. 生产环境构建
```bash
pnpm build
# 产物生成于 dist/ 目录，支持部署至 Cloudflare Pages、Vercel、GitHub Pages 或任何静态 CDN
```
